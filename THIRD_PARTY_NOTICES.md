# Third-party components

The image contains Qwen/Qwen2.5-VL-7B-Instruct, distributed by the Qwen team
under Apache-2.0 according to its official model card. Model revision:
`cc594898137f460bfe9f0759e9844b3ce807cfb5`.

Source and attribution: <https://huggingface.co/Qwen/Qwen2.5-VL-7B-Instruct>.
The model's original README is retained in `/models/qwen/README.md`. A copy of
Apache-2.0 is included at `/models/qwen/LICENSE`. The weights are unmodified.
Application prompts, document parsing and retrieval are separate application code.

The mandated AMD ROCm/PyTorch base and installed Python dependencies retain
their own licenses and notices. Their upstream distributions and package metadata
remain in the container. This project does not claim authorship of those components.
